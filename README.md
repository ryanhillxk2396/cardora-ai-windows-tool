## What Cardora AI Does

Cardora AI is built for Windows teams producing marketplace product cards and infographic visuals at scale. Its workflow is organized around Photoshop, allowing structured product information to be transformed into consistent visual layouts without manually recreating every card.

The application is most valuable for repeated production runs that use a common design format. Excel-driven data, connected media files, and AI image enhancement help reduce repetitive publishing steps while keeping larger desktop content batches easier to manage.

## Workflow

The usual production sequence is:

1. Create an Excel sheet containing product information, names, and card copy.
2. Add the required images and connect them to the project structure.
3. Open the Photoshop automation workflow.
4. Start the batch operation to produce product cards or infographic versions.
5. Apply the upscaling stage when the finished artwork requires higher-resolution output.

The main responsibilities of each component are:

- **Excel:** supplies organized product data
- **Photoshop:** provides the composition and layout layer
- **Computer vision:** supports automated desktop interaction
- **Real-ESRGAN:** enlarges images for final visual assets
